| **2.1.0** | **New:**<br>• A *Highlighting spawner* status while the highlight is on.<br>• New icons for the Protect and Highlight buttons and the *Protecting spawner* and *Protected spawner nearby* statuses. Each status shows how the spawner is kept safe, and a red cross on a button means it is off.<br>**Changes:**<br>• Hits on a protected spawner are blocked from any distance. **Protection Range** now only sets when you get the status.<br>• **Boosted Health** now defaults to 100,000 (was 10,000). An existing config keeps its value, so change it there.<br>• On a server with the mod, a protected spawner can never be destroyed. If one breaks anyway, the server brings it straight back at full health.<br>• Protection and its history are saved on the spawner itself, with the world, instead of in a list file on each computer. It stays when the mod is added to or removed from the server.<br>• The Compendium lists every protected spawner in the world on a server with the mod. On a server without it, it lists the ones you have been near and remembers them between sessions.<br>• The **Server Protection** and **Share With Players** settings are gone, as they are no longer needed.<br>Spawners protected with 2.0.0 need to be protected again. When the server has the mod, players need the same version. |
| **2.0.0** | **Rebuilt** for the current game and BepInEx.<br>**New:**<br>• Protect the closest spawner from two buttons that slide out next to your inventory, instead of keyboard shortcuts and hitting it.<br>• A highlight button paints the nearest spawner in a pulsing color you can see through walls.<br>• Protected spawners sit in a shield bubble (color and opacity adjustable) and give a *Protecting spawner* (or *Protected spawner nearby*) status while you are near.<br>• Looking at a protected spawner shows who protected it.<br>• A **Protected spawners** page in the Compendium lists every protected spawner with who protected it and when, where it is, when it was last guarded and last blocked a hit, and a **Show on map** button.<br>• New icon.<br>**Protection:**<br>• Hits from anyone are blocked while you are within 20 m, not just your own.<br>• A server with the mod keeps protected spawners at full health by itself, so nobody can destroy them.<br>• Every destructible spawner is found automatically, including the Deep North's Wardrobe Shafts and Malicious Ice.<br>**Sharing:**<br>• A server with the mod keeps one list for everyone (**Who Can Change Protection**: anyone, admins only, or only the protector and admins).<br>• On a server without the mod, players with the mod share their lists while they play together.<br>• Lists are saved per world, and changes are ordered by game time, so a wrong computer clock can't undo them.<br>Keyboard shortcuts and 1.x settings are gone, and spawners protected with 1.x need to be protected again. When the server has the mod, players need the same version. |
